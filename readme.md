# Manikant Mishra Portfolio

This repository contains the portfolio website of Manikant Mishra. For questions, contact <samp><a href="mailto:manimishra2006@gmail.com">manimishra2006@gmail.com</a></samp>.

<br>

To setup a dev environment:

```bash
# Clone the repository

# Install dependencies
npm i

# Run the local dev server
npm run dev
```

To serve a production build:

```bash
# Install dependencies if not already done - 'npi i'

# Build for production
npm run build

# Serve the build using express
npm start
```

## Deploy to Vercel

The project is configured as a static Vercel deployment. Vercel installs dependencies with `npm ci`, builds with `npm run build`, and serves the generated `public` directory.

```bash
npx vercel
npx vercel --prod
```

The local Express server in `server/index.ts` is for local testing. It is not required by the current static portfolio deployment.
